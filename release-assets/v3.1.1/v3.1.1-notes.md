# Spool Studio 3.1.1

This update fixes existing filament names being changed when editing a spool ([issue #10](https://github.com/GeorgHo/SpoolStudio/issues/10)).

- Existing filament names keep their full length, capitalization and spelling when changing spool data, selecting a color or importing RFID metadata.
- The field is now labeled **Filament Name**. Names are no longer automatically formatted or limited to 40 characters in the form. Rename a product explicitly, or use **Use suggested color as filament name** to replace it with a color suggestion.
- **Clear printer assignment** keeps tag links. It no longer falls back to `SET_SPOOL_ID=0`, which also unlinks legacy UIDs in Paxx12 firmware `2.0.0-paxx12-24`. A later RFID scan may assign the spool again.
- **Manage tag links → Unlink** remains a separate, confirmed action. It removes the tag's native and compatibility links without clearing an already loaded printer assignment.
- Settings now explain that firmware `2.0.0-paxx12-24` still requires compatibility mode: leave **Native tags only** off and retain `card_uids` when migrating.

Validation: **128 automated tests passed**; debug build and Android Lint completed successfully (zero lint errors). Physical NFC / U1 testing remains outstanding.

Version: **3.1.1** · Android version code: **25**.

Please test whether updating an existing spool now preserves its original filament name and report your results in [issue #10](https://github.com/GeorgHo/SpoolStudio/issues/10).
