# Spool Studio 3.1.2

This patch fixes dark text on the dark NFC/RFID settings background ([issue #11](https://github.com/GeorgHo/SpoolStudio/issues/11)).

- The NFC/RFID tag storage descriptions and **Native tags only** label now use explicit light text colors.
- Settings cards provide a matching light default content color, keeping unstyled text readable on their dark background.
- Tag-storage checkboxes, migration controls and tag-link buttons use the existing dark UI palette.
- Migration preview/result dialogs and the unlink confirmation now use matching dark backgrounds and light text.

The changes affect presentation only; tag lookup, migration and storage behavior are unchanged.

Validation: debug build and Android Lint completed successfully. The affected settings text and checkbox label were visually checked in the Android emulator.

Version: **3.1.2** · Android version code: **26**.
